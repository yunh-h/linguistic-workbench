# 閱讀工作台 UI 改版

參考使用者提供的 `linguistic-workbench-preview.html`（Windows Documents/Codex），將原本的大標語、綠色漸層、圓角卡片改為紙面背景、細分隔線、低彩度藍色與襯線原文。保留現有原生 HTML／CSS／JavaScript，未新增 UI 套件或外部字型請求。

## 實作範圍

- 頂層「輸入／分析／紀錄」為三個獨立畫面，一次只顯示一頁。輸入頁只呈現編輯器；分析完成或開啟歷史快照後進入分析頁。編輯原文返回輸入頁，切換本身不清除原文、選取詞語或搜尋條件。
- 分頁使用 URL hash，支援瀏覽器前後頁、重新整理與鍵盤導覽。沒有結果時分析頁顯示入口提示；處理中的結果晚到，不會把使用者從另選的分頁拉走。保存未完成會在紀錄導覽標示數量。
- 逐詞按鈕顯示真實 surface、gloss 與 UPOS；合併詞仍只呈現一份 surface，可在側欄切換分析單位。標點保留，完整原文另以未正規化的文字呈現。
- 「逐詞／句法／語法說明」為實際 tabpanel；支援左右方向鍵、Home／End 和選取狀態。句法表直接使用 parser dependency，不代入預覽的手寫分析。
- 固定寬度詞語側欄，窄螢幕移到閱讀區下方；語言延伸欄位改為原生 details，可自行展開。來源、分歧與未知值保留。
- 原生 dialog 來源抽屜列出 Analysis 中的實際來源，支援 Escape、關閉按鈕與焦點返回。詞語依據包含詞語欄位、相關註解與分歧的 source IDs，不冒充人工驗證。
- 無翻譯、無構式時顯示明確說明，不加入示意 gloss、虛構翻譯或預覽中的語法例句。
- 亮色／深色配色依系統偏好切換；沒有新增動畫或模型請求。歷史、匯入、版本、重試與追問仍沿用原流程。
